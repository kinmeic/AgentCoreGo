## 验证与边界

验收环境为 macOS arm64、CGO/SQLite、Go 1.26.10。执行模块校验、gofmt、vet、全量标准/race 测试、原生构建与两份配置校验；Linux/Windows amd64 使用 `CGO_ENABLED=0` 交叉构建。govulncheck v1.9.0 分别以 Darwin、Linux 和 Windows 目标分析项目，使用 Go 1.26.10 标准库。

以上检查通过，三个目标的漏洞扫描均返回 `No vulnerabilities found`。容器配置校验使用测试 AUTH_TOKEN，未使用生产密钥。

本轮没有执行 Docker 镜像或 Linux/Windows 实机测试，也没有连接真实模型或外部 MCP 服务。终端仍具有进程的 OS 权限；Workspace 服务仍不能与其他进程形成跨进程事务，恢复期间的 I/O 故障可留下部分变更，恢复前的补偿快照供显式恢复使用。

升级后 shell 自动只读判定更严格，调用方应使用专用文件/Git 工具或正常审批流程。外部 JSON Schema 引用需改为内嵌定义。工作流恢复只复用相同任务且实际输入匹配的完成记录；此前被错误丢弃的 args 现在参与执行和缓存判定。
